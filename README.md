# NACOSS Excos ID Card Management System

A student ID card management project created by **Chahyaandida Ishaya** for the departmental union of the Nigeria Association of Computer Science Students (NACOSS).

## Project background

The system was used by the departmental union to generate identity cards for its executive members (Excos). It served as a departmental test of the project in an association setting.

## About NACOSS

NACOSS stands for the **Nigeria Association of Computer Science Students**.

## Project archive

The repository contains the project source as [NACOSSIDCARD.zip](NACOSSIDCARD.zip). Extract the archive to review the application files and any included setup materials.
